# 生态集成说明

> ⚠️ 以下所有集成均为**可选项**，仅在用户**明确提出需求**时才激活，每次操作均需用户确认。

## AgentMail
如用户明确要求将报告发送到邮箱，按用户提供的地址发送。

## agent-reach
如用户明确要求订阅职业方向资讯，根据用户选择的方向提供订阅服务（可随时取消）。

## MEMORY.md / memory 文件
如用户明确要求保存规划摘要，提供内容供用户自行保存，不主动写入。

## Tavily API
仅在用户明确需要实时招聘数据且当前环境可用时接入。

## 多语言支持
如用户要求，提供英文版本参考。

## 重要原则

- **不自动发送**：不自动发送任何报告、资讯或推送
- **不自动订阅**：不自动订阅任何内容
- **不自动记录**：不主动写入任何 memory 或追踪文件
- **用户授权**：每次外部操作均需用户明确授权
