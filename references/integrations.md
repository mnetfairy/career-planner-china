# v2.0 生态集成（全部为可选，默认关闭）

以下每项集成**仅在用户明确提出需求**时启用；默认全部不调用、不联网、不写盘。

## AgentMail 集成
- 仅在用户明确要求把报告发送到指定邮箱时启用。
- 发送前必须回显收件地址与报告内容摘要，取得用户确认后再发送。
- 默认不发送。

## agent-reach 集成
- 仅在用户明确要求订阅职业方向资讯时启用。
- 默认不订阅。

## MEMORY.md / 用户档案集成
- 仅在用户明确要求"记住我的职业规划"时，才写入档案摘要。
- 默认不创建用户档案、不写入任何 memory 文件。
- 写入前回显要写入的字段，用户确认后再写。

## 多语言支持
- 仅在用户明确要求英文报告时启用。

## 实时数据接入
- 仅在用户明确要求查实时招聘信息且宿主环境允许时，通过 Tavily 获取。
