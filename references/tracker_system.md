# 职业规划追踪系统

> ⚠️ 仅在用户明确要求保留记录时创建/写入；默认不创建、不写入任何文件。

## 用户状态文件

保存路径：`~/.openclaw/workspace/memory/career_tracker_{user_id}.json`

**创建与写入门控**：仅在用户明确要求「保留追踪记录 / 记住我的职业规划」时才创建或写入该文件；默认不创建、不写入任何 memory 文件。写入前回显要写入的字段，用户确认后再写。

## 追踪节点
- 7天：首次跟进，问候+执行困难
- 30天：月检视，对照目标评估进展
- 90天：季度复盘，决定是否调整方向
- 年度：全面回顾，重新生成规划

## 复盘问卷
1. 上次推荐的行动，你做了哪些？
2. 有遇到什么困难吗？
3. 现在对方向还有信心吗？
4. 有没有发现新机会或新想法？
